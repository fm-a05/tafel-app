# Tafel-app

Deze Tafel-app is gemaakt voor het vak Rekenen. Met deze applicatie kunnen leerlingen de maaltafels bekijken en oefenen.

## Features

- Kies een tafel en bekijk de volledige tafel van 1 t/m 10.
- Genereer willekeurige oefeningen voor een gekozen tafel.
- Vul je antwoord in via een invoerveld.
- Controleer direct of je antwoord juist is.
- Ontvang onmiddellijke feedback op je antwoord.

## Gebruikte technologieën

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
